# Window Sweaters for Windows

A native Windows port of the excellent work by Sara Gordic[Github](https://github.com/saragordic/) [Twitter](https://x.com/saragordic) [Window Sweaters](https://github.com/saragordic/window-sweaters), which draws knitted borders around open windows.

This is a work in progress, if you encouter them please file them here and not on Sara's macOS repo.

App will be available via Microsoft Store soon. I will update the README with a link once it is approved.
