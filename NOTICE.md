# Attribution

This Windows implementation ports Window Sweaters by Sasa Gordic:
https://github.com/saragordic/window-sweaters

The reviewed source baseline is
`a49dff52483dafdbe27f972bd271cd28d37cef1c`.
Windows-specific adaptations use Win32, Direct2D, DirectComposition, and
C++/WinRT WinUI 3 instead of the original macOS APIs.

Window Sweaters is derived from JankyBorders by Felix Kratz:
https://github.com/FelixKratz/JankyBorders

The existing GNU General Public License, version 3, is preserved in LICENSE.
Window Sweaters adds the procedural knit renderer, curated app colourways,
menu-bar controls and window-tracking refinements.

Application names in the collection belong to their respective owners and are
used to describe colourway inspiration. No affiliation or endorsement is implied.
The catalogue images are generated by the original project's renderer.

The original hero and social-preview images are stylized AI-generated promotional
mockups. They are separate from the collection plates, which show the actual app
renderer. Those promotional images are not fidelity baselines for this port.
